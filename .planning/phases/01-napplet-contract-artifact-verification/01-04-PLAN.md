## Trust Boundaries

| Boundary | Description |
|---|---|
| approved candidate → image intake | Only the exact approved source/release/tarball/executable integrities may be fetched. |
| host runner → Docker isolation runtime | Untrusted toolchain commands must cross one immutable policy-enforcing argv boundary. |
| sealed container → host/network/secrets | The container must have no network interface, credentials, privilege, host-writable path, or unbounded resource route. |
