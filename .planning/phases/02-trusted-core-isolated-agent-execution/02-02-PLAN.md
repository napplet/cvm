## Trust Boundaries

| Boundary | Description |
|---|---|
| unknown payload → admission | Potentially malformed or oversized user data is parsed and measured. |
| admitted text → risk detector | A fallible classifier observes bounded data but cannot determine authority. |
| admission decision → executor | Only a fully accepted deterministic decision may reach allocation/billable hooks. |
