## Trust Boundaries

| Boundary | Description |
|---|---|
| User text -> Phase 2 admission | Untrusted idea/encoding crosses into action authorization. |
| Coordinator -> ModelGateway | Only a persisted operation intent may cross toward a billable provider effect. |
| Gateway receipt -> financial authority | Untrusted adapter/provider data becomes chargeable only after strict correlation and pinned-card pricing. |
| Worker/artifact evidence -> session commit | Generated output can advance a session only after existing server-owned verification. |
