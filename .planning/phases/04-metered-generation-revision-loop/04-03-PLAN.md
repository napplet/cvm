## Trust Boundaries

| Boundary | Description |
|---|---|
| Provider dispatch deadline -> persisted state | A local timeout cannot establish whether the remote effect occurred. |
| Reconciliation service -> ModelGateway lookup | Recovery must query the original identity and possess no fresh-dispatch authority. |
| Found receipt -> finalizer | Late provider evidence becomes chargeable only after full correlation and pinned-card checks. |

## STRIDE Threat Register — ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-AMBIGUITY | Tampering | dispatch timeout/loss | high | mitigate | Persisted intent, explicit usage_unknown, pre-action block, original-only lookup, and zero-fresh-invocation tests in Task 2. |
| T-04-DOUBLE | Repudiation | concurrent receipt/reconciliation | high | mitigate | Unique receipt/finalization identities, terminal reread, reconciliation claim, and concurrent count assertions. |
| T-04-MISMATCH | Spoofing | late receipt correlation | high | mitigate | Strict server operation/provider request/provider/model/profile/card match before finalization; mismatch quarantines without debit. |
| T-04-NATIVE | Information disclosure | provider-native fixture evidence | medium | mitigate | Protected evidence reference/digest split from normalized observation and public result in Task 1. |
| T-04-BLOCK | Denial of service | unresolved usage_unknown | medium | accept | Blocking is the locked spend-safety outcome; status exposes reconciliation state and operator evidence, while Phase 7 owns live operational deadlines. |
| T-04-SC | Tampering | provider adapter dependency | high | mitigate | No provider package is installed or imported; deterministic project-owned gateway is the only implementation. |
