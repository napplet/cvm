<objective>
Close the Phase 04 evidence-integrity blocker by making the twenty-case release gate observe and compare actual runtime effects before it can produce passed case or aggregate evidence.

Purpose: Restore the Plan 04-06 promise that the deterministic gate proves D-59 through D-78 from executable Phase 04 authorities rather than allowing fixture declarations plus child exit codes to self-certify.
Output: A strict runtime-observation contract, twenty actual observation scenarios, per-field fail-closed comparisons, observed-only aggregate derivation, and regenerated content-addressed design evidence.
</objective>

<gap_analysis>
Root cause category: plan deficiency. Plan 04-06 required actual state/effect oracles but did not require a shared structured observation channel or require the evidence evaluator to distinguish expected fixture data from runtime facts. The execution therefore preserved the service tests yet reduced their result to an exit code and let the fixture supply case effects. This plan closes that missing contract and derives both case status and aggregate evidence from runtime observations.
</gap_analysis>
