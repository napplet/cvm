<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| verified-artifact store -> preview service | Stored artifacts/manifests are treated as untrusted until exact verification identities are checked. |
| host/runtime -> service | Descriptors and runtime messages are untrusted and have no publication authority. |
| external signer -> service | A completed event is untrusted until cryptographic and semantic verification succeeds. |
| service -> deployment/attestation ports | External effects require durable child intents and exact sealed inputs. |

## STRIDE Threat Register (ASVS L1, block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-01-S | Spoofing | owner event | high | mitigate | Verify principal/event bindings through `OwnerEventVerifierPort` before any effect. |
| T-06-01-T | Tampering | artifact-to-publication chain | high | mitigate | Carry and compare exact artifact/manifest/capability hashes at every boundary. |
| T-06-01-R | Repudiation | publication effects | high | mitigate | Persist immutable intent, operation, and observation identities before projecting success. |
| T-06-01-I | Information disclosure | schemas/status | high | mitigate | Public event fields and owner-safe allowlists only; never serialize secrets or raw provider output. |
| T-06-01-D | Denial of service | replay/concurrency | medium | mitigate | Bounded schemas, idempotency fingerprints, one claimant per effect, and no queue. |
| T-06-01-E | Elevation of privilege | preview/runtime | high | mitigate | Exact-artifact short-lived grant with zero signer, relay, storage, or publication authority. |
| T-06-SC | Tampering | dependency identity | high | mitigate | Add no package install; later plans pin the already researched CLI and NIP-01 identities through `COVERAGE.md`. |
