<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| ContextVM principal -> intent service | Signed transport identity is normalized to the owner and checked against session/artifact ownership. |
| external signer -> event verifier | The completed event is attacker-controlled until crypto and semantic checks finish. |
| verifier -> attestation builder | Only verified, owner-bound public facts may enter the service attestation. |

| T-06-03-S | Spoofing | owner event | high | mitigate | Recompute NIP-01 id/signature and require exact verified principal pubkey. |
| T-06-03-T | Tampering | intent/template/event | high | mitigate | Versioned canonical bytes plus exact comparison of every artifact/d-tag/capability/policy/expiry fence. |
| T-06-03-R | Repudiation | owner/attestation records | high | mitigate | Persist distinct immutable identities and cross-links for intent, owner event, and attestation. |
