## Trust Boundaries

| Boundary | Description |
|---|---|
| service -> promoted CLI source facade | Artifact bytes, event, deploy plan, servers, and relays cross into external publication code. |
| pinned source evidence -> source contract result | Source contents and fixture claims are untrusted until exact commit, asset SHA, file hashes, exports, and rejected paths agree. |

| Blossom/relay/CLI output -> persistence | External observations are untrusted, partial, duplicate, late, or ambiguous. |
| reconciliation -> external systems | Reconciliation is observation-only and must not create another side effect. |
