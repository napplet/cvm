<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Nostr/ContextVM -> adapter | Signed envelopes, arguments, raw tags, and public events are untrusted until correlation/schema/owner checks. |
| adapter -> domain services | Only normalized owner identity and strict project commands may cross. |
| service status -> host surface | Status is owner-scoped but still projected through an explicit safe field/action allowlist. |
| source contract result -> announcement/adapter | A supplied availability result is untrusted until its exact commit, asset SHA, and available state validate. |
| host controls/runtime -> adapter | User actions and runtime messages cannot bypass the signed tool or persisted intent. |

## STRIDE Threat Register (ASVS L1, block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-06-S | Spoofing | ContextVM owner/action | high | mitigate | Use verified pubkey, request-event correlation, strict action schemas, and owner-scoped service calls. |
| T-06-06-T | Tampering | host action/status | high | mitigate | Bind commands to stored intent/fingerprint and project only immutable linked identities. |
| T-06-06-C | Tampering | publication availability | high | mitigate | Require Plan 05's validated exact-source result before announcing or dispatching publication; fail closed with zero effects. |
| T-06-06-R | Repudiation | publish command | high | mitigate | Persist canonical invocation/request-event/intent/operation identities before effects. |
| T-06-06-I | Information disclosure | notifications/host surface | high | mitigate | Explicit allowlists, safe errors, labelled hashes/ids, and no protected/raw/provider fields. |
| T-06-06-D | Denial of service | duplicate actions | medium | mitigate | Strict bounds, idempotency, disabled unsafe duplicates, no queue, and quiet replay. |
| T-06-06-E | Elevation of privilege | preview/top-up/runtime | high | mitigate | Separate read/payment actions from publication submit and require verified completed event plus persisted intent. |
| T-06-SC | Tampering | ContextVM/runtime dependencies | high | mitigate | Reuse locked SDK/Zod stack and add no package install. |
