<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| candidate/release inputs -> controller state | Candidate-controlled bytes must not choose topology, cost scope, certifier authority, or state transitions. |
| provider discovery -> authorization request | Native capability/auth responses are untrusted and must become finite redacted facts. |
| authorization request -> later provider effects | Only the exact approved request digest may unlock provisioning. |
