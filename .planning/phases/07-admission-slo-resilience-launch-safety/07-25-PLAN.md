## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI to release controller | Candidate and resume intent cross from the operator process into the authoritative state machine. |
| Controller to provider APIs | Authorized provisioning, discovery, suite operations, and teardown cross external provider trust boundaries. |
| Generated material to dynamic loaders | Generated config, registry module, and trust-root bytes become executable/authoritative only after root confinement and digest verification. |
| Live adapters to evidence store | Untrusted provider responses become candidate-bound protected observations. |
| Evidence store to evaluator and bundle | Persisted records can authorize promotion only after freshness, provenance, binding, and digest checks. |
| Controller to cleanup APIs | Destructive calls must remain confined to resources proven to belong to the authorized run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-25-01 | Spoofing | Protected registry and observations | high | mitigate | Generate the exact-eight registry, digest-pin its module, require real-provider provenance and exact candidate/topology/source/adapter bindings, and reject alternate registry/evidence inputs. |
| T-07-25-02 | Tampering | Resume state and generated certifier material | high | mitigate | Canonical digest chain, create-only content-addressed writes, predecessor verification, root confinement, and full-chain remeasurement before resume. |
| T-07-25-03 | Repudiation | Provider and suite operations | high | mitigate | Persist stable operation IDs, input/output digests, attempts, timestamps, authorization consumption, and evidence pointers for every step. |
| T-07-25-04 | Information disclosure | Secret references and command output | high | mitigate | Broker references at adapter call time, never persist secret values, redact structured logs, and test output for secret-value absence. |
| T-07-25-05 | Denial of service | Interrupted or ambiguous external operations | medium | mitigate | Inspect-before-retry reconciliation, bounded backoff/attempts, resumable per-operation state, and explicit terminal blocked states. |
| T-07-25-06 | Elevation of privilege | Cost/effect authorization | critical | mitigate | Bind every operation to the approved authorization digest, reserve cleanup capacity before creation, reject exhaustion/expansion, and prohibit runtime approval mutation. |
| T-07-25-07 | Tampering | Trust finalization and release evaluation | critical | mitigate | Require all eight fresh passed records, remeasure the source and generated pins, load the finalized trust root through the pinned loader, and invoke the sole evaluator exactly once before bundle creation. |
| T-07-25-08 | Elevation of privilege | Cleanup resource scope | high | mitigate | Permit only delete/release operations for persisted run-owned resource IDs and regions, use provider idempotency keys, and make unresolved required cleanup promotion-blocking. |
| T-07-25-SC | Tampering | Package/runtime supply chain | high | mitigate | Add no new package; retain pinned lockfiles and existing supply-chain certification, run slopcheck where configured, and block on any newly introduced assumed or suspicious dependency. |
</threat_model>
