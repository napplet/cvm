## Trust Boundaries

| Boundary | Description |
|---|---|
| Nostr/ContextVM/payment/model networks → controller | Signed events, payment receipts, and usage facts cross untrusted networks. |
| compatible host/NIP-46 → CVM | Browser facts and user-owned signatures return without private-key custody. |
| CLI/upload/relay providers → publication journal | External mutation outcomes determine public release effects. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07-42-01 | Spoofing/Tampering | ContextVM/payment/model clients | critical | mitigate | Exact signed correlation, receipt/request/operation binding, official SDK/rail schemas, and original-operation reconciliation. |
| T-07-42-02 | Information Disclosure | service/user keys | critical | mitigate | External named references only; separate service roles; disposable NIP-46 client; secret-canary rejection at config/log/evidence boundaries. |
| T-07-42-03 | Elevation of Privilege | compatible host/signer | critical | mitigate | Real reference host/Chromium, sealed-artifact binding, host-owned UI facts, and external signature verification before publication. |
| T-07-42-04 | Tampering/Repudiation | CLI/upload/relay | high | mitigate | Pin exact source/bytes, exact file/event sets, persist operation before effect, query the original mutation after ambiguity. |
