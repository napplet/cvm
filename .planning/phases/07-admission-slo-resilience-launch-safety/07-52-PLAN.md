<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser -> local relay -> ContextVM server | Untrusted signed/encrypted messages and payment tags cross into the service identity and MCP boundary. |
| Payment rail -> ledger | Untrusted/replayed Cashu and NWC settlement evidence may create monetary credit. |
| Server -> browser UI | Durable financial state crosses into a user-visible projection. |
| Browser/contained test image -> host | Disposable user secrets and service credentials must remain in their owning process. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07DEV52-01 | Spoofing | ContextVM browser/server identity | high | mitigate | Official SDK signature/encryption validation, event-ID preservation, service-pubkey pinning, and negative forged-event browser test. |
| T-07DEV52-02 | Tampering | Payment tags and settlement evidence | high | mitigate | Immutable request-local tags, rail verification, SQL uniqueness, and replay/restart integration assertions. |
| T-07DEV52-03 | Information disclosure | User/service/payment secrets | high | mitigate | Browser-only user key, server-only service material, redaction assertions across storage/markup/URLs/logs, and no HTTP command payloads. |
| T-07DEV52-04 | Denial of service | Settlement observation | medium | mitigate | Bounded deadlines/backoff and durable pending-state scan without unbounded worker creation. |
| T-07DEV52-05 | Elevation of privilege | HTTP development surface | high | mitigate | Loopback binding, strict route allowlist, and network-trace test proving commands use ContextVM. |
