<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| ContextVM command -> model intent | Untrusted bounded text and prior-artifact references enter a paid external effect. |
| Model provider -> proposal store | Untrusted generated source and usage cross into durable service-owned state. |
| Proposal store -> worker contract | Stored source may reach isolated code execution only when every owner/action/digest/surface binding matches. |
| Price sources -> prepaid ledger | External provider and conversion facts determine a sat-denominated maximum and final charge. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07DEV53-01 | Tampering | Prompt/prior artifact/proposal binding | high | mitigate | Canonical request fingerprint, owner/session/action/version binding, immutable proposal digest, approved paths, and mismatch tests. |
| T-07DEV53-02 | Repudiation | Provider usage and lookup | high | mitigate | Original operation/response identity, authoritative normalized usage, SQL uniqueness, persisted-before-complete proposal, and lookup-only recovery. |
| T-07DEV53-03 | Tampering | Price source and sat conversion | high | mitigate | Exact provider/model source bytes and conversion digests, timestamps/freshness, checked rational math, and fail-closed stale/mismatch cases. |
| T-07DEV53-04 | Information disclosure | Provider/source store | high | mitigate | Server-only credentials, bounded source fields, owner-scoped reads, secret scans, and safe provenance references. |
| T-07DEV53-05 | Denial of service | Provider output/proposal persistence | medium | mitigate | Input/output/file/path limits, provider deadlines, one-operation reconciliation, and bounded SQL rows. |
| T-07DEV53-SC | Tampering | dependency state | high | mitigate | Built-in fetch and existing packages only; root manifest hash gate and no package-manager install. |
</threat_model>
