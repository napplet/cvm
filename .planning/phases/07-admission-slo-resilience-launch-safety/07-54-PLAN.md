<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Paused command -> checkpoint store | User intent and execution authority become durable resumable state. |
| Funding settlement -> explicit resume | New money exists before the user grants new execution consent. |
| Checkpoint -> resumed provider/worker | Stored untrusted state can trigger paid/code-execution effects only after revalidation. |
| Prior artifact/revision -> successor | Cross-version data and ownership enter a new model/build action. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07DEV54-01 | Tampering | Pending-action checkpoint | high | mitigate | Encrypted integrity-bound envelope, digest/owner/version/policy/toolchain/ceiling validation, and tamper tests. |
| T-07DEV54-02 | Elevation of privilege | Explicit resume | high | mitigate | Signed owner-bound ContextVM action, lease fencing, sufficient-balance recheck, and no settlement-triggered execution. |
| T-07DEV54-03 | Repudiation | Duplicate resume/revision charge | high | mitigate | Separate idempotency identities, immutable ledger/version records, lookup-only recovery, and restart injection. |
| T-07DEV54-04 | Information disclosure | Checkpoint and prior artifact | high | mitigate | Server-only encrypted bytes, safe UI metadata projection, owner authorization, and log/browser secret scans. |
| T-07DEV54-05 | Denial of service | Repeated resume/revision | medium | mitigate | Expiry, bounded payloads, lease exclusivity, action maximums, and deterministic terminal projection. |
| T-07DEV54-SC | Tampering | package/toolchain state | high | mitigate | No new dependency intake; revalidate the promoted toolchain ID and root manifest hashes on resume. |
</threat_model>
