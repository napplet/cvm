## Trust Boundaries

| Boundary | Description |
|---|---|
| Proposal store -> worker container | Untrusted generated source enters isolated filesystem and command execution. |
| Worker output -> verifier/repository | Untrusted bytes and command claims request promotion into immutable user-visible artifacts. |
| Preview descriptor -> grant/asset server | An opaque token requests exact owner/artifact bytes across HTTP. |
| Paja outer host -> generated iframe | Trusted local host mediation surrounds untrusted code with opaque origin and denied direct authority. |

## STRIDE Threat Register (ASVS L1; block on high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-07DEV56-01 | Elevation of privilege | Worker/container | high | mitigate | Pinned image/platform, unprivileged/read-only/resource-bounded runtime, no credentials, no network, approved write surfaces, and closed commands. |
| T-07DEV56-02 | Tampering | Verifier/artifact repository | high | mitigate | Independent manifest/aggregate/object/evidence hashing, SQL/object atomicity, containment, immutable versions, and failure injection. |
| T-07DEV56-03 | Spoofing | Preview grant/owner | high | mitigate | Hashed opaque grants bound to owner/session/artifact/version/object/expiry, signed ContextVM projection, and cross-owner/replay tests. |
| T-07DEV56-04 | Information disclosure | Preview asset/iframe | high | mitigate | Exact sealed-file allowlist, traversal/MIME/CORS/CSP controls, opaque origin, no secrets/storage/signer/relay/network, and byte-negative cases. |
| T-07DEV56-05 | Tampering | Compatible-host provenance/policy | high | mitigate | Exact official Paja version/integrity/API, startup policy probe, runtime sandbox/capability assertions, and zero-error Chromium record. |
| T-07DEV56-06 | Denial of service | Build/Chromium/host | medium | mitigate | Per-stage deadlines, CPU/memory/PID/file/output bounds, cleanup, readiness preflight, and one-operation restart observation. |
| T-07DEV56-SC | Tampering | worker/host package intake | high | mitigate | Reviewed exact paja/Playwright/toolchain versions and integrity, frozen isolated lock, pinned Docker base, root hash gate, and no floating/sibling source. |
